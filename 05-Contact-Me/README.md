## 1. The `&lt;a&gt;` (Anchor) Tag

**What it is:** The HTML element that creates hyperlinks to other pages, files, email addresses, phone numbers, or locations within the same page.

**Code snippet:**
```html
&lt;a href="https://example.com"&gt;Clickable text&lt;/a&gt;
