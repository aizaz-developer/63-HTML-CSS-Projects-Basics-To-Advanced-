# Project 14: Text Alignment Lab

A single-page lab demonstrating CSS text positioning and transformation:
`text-align`, `letter-spacing`, `word-spacing`, and `text-transform`.

## Topics Covered
- `text-align` — left, center, right, justify
- `letter-spacing` — tight to wide character spacing
- `word-spacing` — tight to wide word spacing
- `text-transform` — uppercase, lowercase, capitalize
- Combining properties for stylish headings

## What I Built
A text styling showcase with multiple sections:
- Alignment demo: left, center, right, and justified paragraphs
- Letter spacing demo: negative, normal, wide, extra-wide
- Word spacing demo: tight, normal, loose
- Text transform demo: uppercase, lowercase, capitalize
- A combined "hero heading" using all properties together
