Layer Breakdown

Margin

Transparent space outside the border. Pushes other elements away.

Border

The visible edge around padding. Controlled by width, style, and color.

Padding

Space inside the border. Uses the element's background color.

Content

The actual text, images, or child elements. Sized with width and height.

box-sizing Comparison

content-box

width = content only. Padding and border add to total size.

border-box

width = content + padding + border. Total size stays fixed.

Margin Collapse

When two vertical margins touch, the larger one wins. They do not add up.

Box A — margin-bottom: 40px

Box B — margin-top: 20px

Result: 40px gap (not 60px)
