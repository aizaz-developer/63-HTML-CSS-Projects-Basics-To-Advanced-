# Project 15: The Box Model Visual

An interactive diagram that visualizes the CSS Box Model:
`content`, `padding`, `border`, and `margin`.

## Topics Covered
- `content` — the inner text/image area
- `padding` — space inside the border
- `border` — the visible edge
- `margin` — space outside the border
- `box-sizing: border-box` vs `content-box`
- Margin collapse concept

## What I Built
A visual diagram page with:
- A large nested box showing all 4 layers in different colors
- A labeled breakdown section explaining each layer
- A `box-sizing` comparison demo
- A margin collapse visual example
