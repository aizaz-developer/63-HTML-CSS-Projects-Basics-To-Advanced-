# Project 08: Sign Up Form

A registration page built with semantic HTML form elements.

## Topics Learned
- `<form>`, `action`, and `method`
- `<input>` types: `text`, `email`, `password`, `checkbox`
- `<label>` with `for`/`id` pairing
- `name` attribute for data identification
- `required` attribute for validation
- `<button type="submit">`
