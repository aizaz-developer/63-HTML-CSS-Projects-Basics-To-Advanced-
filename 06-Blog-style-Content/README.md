# Project 06: Tech Article — Brain-Computer Interface

A blog-style tech article page using semantic HTML5 article structure.

## Topics Learned
- `&lt;article&gt;` for self-contained content
- Heading hierarchy `&lt;h1&gt;` through `&lt;h6&gt;`
- `&lt;blockquote&gt;` for quotations
- `&lt;cite&gt;` for creative works and authors
- `&lt;time&gt;` with `datetime` attribute for machine-readable dates
