# Project 04: My Daily Routine

A webpage describing my daily schedule using semantic HTML5 elements.

---

## What I Built

A structured page that breaks my day into themed sections using semantic containers instead of generic divs.

---

## Topics Learned

### 1. Semantic HTML Overview
**What it is:** Using HTML tags that carry meaning about the content's purpose, not just its appearance.

**Why it matters:**
- Screen readers navigate by landmarks (header, main, footer)
- Search engines rank semantic pages higher
- Code is self-documenting — other developers understand the layout instantly

---

### 2. The `&lt;header&gt;` Tag
**What it is:** Introductory content for the page or a section.

**Code snippet:**
```html
&lt;header&gt;
    &lt;h1&gt;My Daily Routine&lt;/h1&gt;
    &lt;p&gt;How I structure my day from dawn to dusk&lt;/p&gt;
&lt;/header&gt;
