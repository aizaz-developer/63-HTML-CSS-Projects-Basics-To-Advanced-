# Project 12: Color Palette Showcase

## What I Learned
- Four ways to define colors in CSS: Named, Hex, RGB, RGBA
- Hex shorthand: #FF0000 can be written as #F00
- RGBA alpha channel controls transparency (0.0 = invisible, 1.0 = solid)
- How to use CSS Grid to layout color swatches

## Files
- `index.html` — 10 color box elements
- `styles.css` — All color definitions and layout

## CSS Properties Practiced
- `color` — text color
- `background-color` — box fill color
- `display: grid` — layout system
- `grid-template-columns` — column definition
- `gap` — spacing between boxes
- `border-radius` — rounded corners
- `padding` — inner spacing
- `text-align` — center text
- `font-weight` — bold labels
