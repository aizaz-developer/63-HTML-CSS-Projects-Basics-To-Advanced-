# Project 13: Typography Playground

A single-page showcase demonstrating CSS typography properties:
`font-family`, `font-size`, `font-weight`, and `line-height`.

## Topics Covered
- `font-family` — choosing and stacking typefaces
- `font-size` — px vs rem units
- `font-weight` — light to bold text
- `line-height` — readable vertical spacing
- Google Fonts integration

## What I Built
A typography showcase page with multiple sections:
- Heading styles with different fonts and weights
- Body text demonstrating line-height
- A font-size comparison scale
- A code/monospace section
- A before/after readability comparison
