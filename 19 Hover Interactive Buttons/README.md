# Project 19: Hover & Focus Lab

An interactive page demonstrating CSS pseudo-classes and cursor states:
`:hover`, `:focus`, `:active`, `cursor`, and `outline`.

## Topics Covered
- `:hover` — styles when mouse is over an element
- `:focus` — styles when element is selected (keyboard/mouse)
- `:active` — styles while element is being clicked
- `cursor` — changing the mouse pointer shape
- `outline` — focus rings and accessibility

## What I Built
- A button gallery with hover, active, and focus states
- A link navigation bar with hover underlines
- An input form with focus styling
- A cursor showcase showing different pointer types
- An outline demo with custom focus rings
