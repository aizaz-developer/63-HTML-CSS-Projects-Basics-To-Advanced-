HTML Cheat Sheet

A quick reference guide for essential HTML tags and concepts.

Document Structure

<!DOCTYPE html>
<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

Text Formatting

  • <strong> — Bold text
  • <em> — Italic text
  • <sup> — Superscript: E = mc2
  • <sub> — Subscript: H2O

Code Display

Use <code> for inline code like console.log().

Use <pre> for preformatted blocks:

function greet() {
    return "Hello, World!";
}

Keyboard Input

Press Ctrl + S to save your file.

Press Alt + F4 to close the window.

Collapsible Sections

What is semantic HTML?

Semantic HTML uses tags that describe the meaning of content, not just its appearance. Examples include <header>, <main>, <article>, and <footer>.

What is the difference between block and inline elements?

Block elements take up the full width available and start on a new line (e.g., <div>, <p>). Inline elements only take up as much width as necessary and do not force a new line (e.g., <span>, <a>).

Why is the alt attribute important?

The alt attribute provides alternative text for images. It is essential for screen readers, displays when images fail to load, and improves SEO.
